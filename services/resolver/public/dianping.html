INSTALL / 安装

你的体验，
你来定稿。

此捷径从 iPhone 直接请求 DeepSeek API。安装时需填写你自己的 DeepSeek API Key；请勿分享填好 Key 的捷径。

版本 1.1.0 2026.10.01

下载「大众点评快写」
  1. 在 iPhone Safari 下载并打开 .shortcut 文件。
  2. 导入时填入自己的 DeepSeek API Key，按系统提示授权网络与剪贴板。
  3. 分享商家信息并输入真实体验，可选最多 6 张照片；预览并检查草稿后自行发布。

DeepSeek API 由你自行开通和管理，可能产生用量费用。商家信息、你的体验和所选照片会从 iPhone 直接发送给 DeepSeek；本站不接收这些内容。图片也会计入 API 用量。

UPDATE / GUIDE

重新下载，
由你确认导入。

  1. 在 Safari 下载上方的当前发布版，并保留自己的 API Key。
  2. 打开文件，按 iOS 提示导入；如果出现替换选项，由你决定是否替换。
  3. 重新填写 Key，确认新版本能生成草稿，再处理旧版。
前往下载

此捷径目前没有自动版本检查或静默更新。导入与运行效果需要在你的 iPhone 上确认。

关于草稿

GOOD TO KNOW

捷径以你提供的真实体验为主观事实来源，商家分享信息只用于识别，照片只补充可见的外观、摆盘和环境，不推断口味或服务。生成内容仍可能有误，请发布前核对。

捷径不会代你发布点评，也不保证生成结果或平台展示。请遵守 DeepSeek 和大众点评的适用规则。
